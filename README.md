# Probill EHR

Probill EHR is an advanced Electronic Health Record (EHR) software solution specifically designed for the US healthcare system. It serves as a comprehensive platform for doctors, clinics, and healthcare providers with powerful, user-friendly tools to streamline medical practice management.

## 🏥 Overview

This modern EHR system combines clinical documentation, patient management, appointment scheduling, and revenue cycle management into a single, integrated platform. Built with cutting-edge web technologies, Probill EHR ensures HIPAA compliance while delivering exceptional user experience and performance.

## ✨ Key Features

### Patient Management

-   Complete patient demographics and medical history
-   Electronic medical records with secure data storage
-   Patient portal for appointment booking and communication
-   Insurance verification and eligibility checking

### Clinical Workflows

-   Customizable clinical templates and forms
-   E-prescribing with drug interaction checking
-   Lab results integration and management
-   Clinical decision support tools
-   Progress notes and treatment plans

### Appointment Scheduling

-   Interactive calendar with drag-and-drop functionality
-   Multi-provider scheduling support
-   Automated appointment reminders
-   Waitlist management
-   Resource and room scheduling

### Billing & Revenue Cycle Management

-   Automated claim generation and submission
-   Real-time eligibility verification
-   Payment processing and tracking
-   Denial management and appeals
-   Financial reporting and analytics

### Reporting & Analytics

-   Comprehensive dashboard with key metrics
-   Custom report generation
-   Practice performance analytics
-   Compliance reporting
-   Data visualization with interactive charts

## 🛠 Getting Started

In the project directory, run:

```bash
npm install
```

Installs all required dependencies.

Then start the development server with:

```bash
npm start
```

Runs the app in development mode.

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

The page will reload on changes, and lint errors will appear in the console.

## ✅ Available Scripts

-   `npm start` — Start the development server
-   `npm test` — Launch the test runner in watch mode

## ⚙️ Technologies Used

### Frontend

-   **React 18** - Modern UI library with hooks and concurrent features
-   **Redux + Redux Saga** - State management with side effect handling
-   **React Router** - Client-side routing and navigation
-   **React Hook Form & Yup** - Form validation and management
-   **Bootstrap 5 + SCSS** - Responsive design and custom styling
-   **i18next** - Internationalization and localization support

### Data Visualization

-   **Chart.js** - Interactive charts and graphs
-   **ApexCharts** - Advanced charting library
-   **FullCalendar** - Feature-rich calendar component

### Development Tools

-   **Flow** - Static type checking for JavaScript
-   **Prettier** - Code formatting and consistency
-   **ESLint** - Code quality and error detection
